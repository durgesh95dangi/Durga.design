Principles

Best practices.

  1. If a metric doesn't prompt an action when it turns red, it does not belong on the main dashboard view.
  2. Never truncate numbers arbitrarily: use clear suffixes like $1.4M with full precision on hover.

FAQ

Common question.

How many widgets should be on a single dashboard screen?

Limit primary dashboard views to no more than 6-8 core widgets. Group secondary metrics into specialized tabbed sub-views.
