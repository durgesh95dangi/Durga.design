Principles

Best practices.

  1. Fixing onboarding friction yields 3x higher impact on ARR than tweaking checkout button colors.
  2. Never present a user with an empty state without an immediate primary action to populate it.
  3. Make destructive actions hard to trigger accidentally, but trivial to undo.
